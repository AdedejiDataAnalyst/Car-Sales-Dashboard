# Car Sales Performance Dashboard

**Tools:** Excel, PivotTables, Slicers, Timelines, PivotCharts

## Overview
An interactive Excel dashboard analysing 1,000 car sales orders, covering sales by maker, model, state, shipping mode and month.

## What I did
1. Organised the order data into a single analysis-ready table.
2. Built 10 PivotTables to summarise sales across makers, models, states, ship modes and months.
3. Designed a dashboard with 5 charts and interactive slicers.

## Key findings
- Total sales were 853.1M from 1,512 units sold.
- Chevrolet was the top-selling maker, at 71.0M.
